## Graph, Queue를 이용한 배달 시스템 및 시뮬레이션 구현

**2025-2 자료구조실습 8조 팀프로젝트 과제**


### 실행 방법

> [!NOTE]
> 본 프로그램은 리눅스 혹은 유닉스 환경에 최적화되어 있습니다. 윈도우 환경에서 실행 시 화면 스크린 초기화 등 일부 기능이 정상적으로 동작하지 않을 수 있습니다. 리눅스 혹은 유닉스 환경에서 실행이 어려운 경우, Github의 본 레포지토리 페이지 상단 우측의 "<> Code" 버튼을 클릭 후, Codespaces 탭에서 새로운 코드스페이스 환경을 생성하여 실행할 수 있습니다.

- 컴파일 및 바로 실행
```bash
make run
```

- 컴파일만 실행 (`/bin/program`에 실행 파일 생성)
```bash
make build
```


### 프로젝트 구조

```
├── src/                # 프로젝트의 메인 소스 코드 디렉토리
│   ├── core/
│   ├── entities/
│   ├── utils/
│   ├── main.cpp
├── build/              # (자동 생성) 중간 오브젝트 파일(.o) 등 빌드 산출물이 저장되는 디렉토리
├── bin/                # (자동 생성) 실행 파일(program 등)이 저장되는 디렉토리
├── docs/               # 협업에 필요한 문서가 저장된 디렉토리 (초기 설계한 class diagram이 저장되어 있음)
├── etc/                # 메인 소스 코드에 병합되기 이전, 각 팀원들의 코드가 저장된 디렉토리
├── Makefile            # 프로젝트 빌드 및 자동화 스크립트 (make build, make run 등)
├── README.md           # 프로젝트 소개 및 실행 방법, 구조 설명 파일
```
